### Hi, I'm Ezra.

I design and build software for the web: small runtimes, developer tools and products, made with care
for how they look and how they feel to use.

**Things I've designed and built**

- **[LaneRouter](https://lanerouter.com)**: live road conditions for AI agents. Check whether a site is blocking
  agents before acting, and report back after. An official LangChain integration.
  [GitHub](https://github.com/lanerouter/lanerouter-sdk) · [npm](https://www.npmjs.com/package/lanerouter) ·
  [PyPI](https://pypi.org/project/lanerouter/)
- **[Auddomate](https://auddomate.com)**: a spectral renderer for 3D artists that runs on the GPU in your browser,
  with results checked against pbrt-v4.
- **[Lucid UI](https://lucidui.dev)**: a 5.8 KB UI runtime for people and AI agents. No build step,
  no dependencies. [GitHub](https://github.com/lucidui-dev/lucidui) ·
  [npm](https://www.npmjs.com/package/@lucidui-dev/core)
- **[Stacktora](https://stacktora.com)**: keeps a project's dev-environment files in sync with its
  stack recipe, `stacktora.json`. [GitHub](https://github.com/stacktora) ·
  [npm](https://www.npmjs.com/package/stacktora)
- **[releaseflip](https://github.com/thisisezra/releaseflip)**: atomic deploys and instant rollback
  for shared hosting. No SSH, and protected files like `.htaccess` are never overwritten.
  [npm](https://www.npmjs.com/package/releaseflip)
- **[loadts](https://github.com/thisisezra/loadts)**: load TypeScript files in any browser with no
  build step. [Live demo](https://thisisezra.github.io/loadts/) ·
  [npm](https://www.npmjs.com/package/loadts)
